# Game design spec

Place the exported spec here as `game-design-spec.md`.

How: open the Claude Doc "Tech Startup Tycoon: Game Design and Technical Specification v1.0", export it as Markdown, and save it in this folder under that name. Re-export whenever the Doc changes, and commit the update with a one-line note in `CHANGELOG.md`.

The two diagrams in the Doc (value chain, runtime architecture) export as text placeholders; the architecture is fully described in ADR-0001 and ADR-0004.

Where the spec and the ADRs differ on a technical detail, the ADRs win (see `CLAUDE.md` §1).
