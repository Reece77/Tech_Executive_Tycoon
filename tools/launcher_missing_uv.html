Tech Startup Tycoon needs uv

The game runs on Python, which uv installs and manages for it. uv is not installed on this computer yet.

  1. Install uv: see uv's install page (one command, or the Windows installer).
  2. Install Node.js 22 or later too, if you have not: the game's screens are built with it on the first run.
  3. Double-click Tech Startup Tycoon in the game's folder again.
